# Academic structure comparison

The public reference checkout was inspected at commit `fab89cb7dedbd9d62b0f1a90df944447f7306c86`. The table describes its presentation and the corresponding AURA structure.

| Element | Reference repository | AURA submission |
|---|---|---|
| Root | Team table, quick links, assignments and course project | Team table, direct links to every lab, project documents and execution evidence |
| Assignments | Flat folder with worklet-prefixed notebook names | One folder per official assignment, preserving the pre-existing lab record and runner alongside the notebook |
| Notebooks | Lab overview, setup, headed code cells and captured runs | Aim, architecture, algorithm, executable demonstration, checks, observations and viva |
| Course project | Documents, originals, code and evidence under the project | Source, architecture, problem statement, reports and demonstration under the project |
| Documentation | Markdown tables and links to academic artifacts | Assignment index and execution ledger with direct relative links |

Reference [Executive Decision Support System](https://github.com/riyamagadum2819/Executive-Decision-Support-System).
